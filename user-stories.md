# 📋 User Stories for Budget Tracking Web App

## 🧑‍💼 User Authentication & Account Management

- [x] As a user, I want to sign up with my email so I can create an account.
- [ ] As a user, I want to log in and log out securely so I can access my personal data.
- [ ] As a user, I want to reset my password in case I forget it.

## 💳 Wallet Management

- [ ] As a user, I want to create multiple wallets (e.g., Cash, Bank, GCash) so I can separate my funds.
- [ ] As a user, I want to view the total balance and individual wallet balances.
- [ ] As a user, I want to edit or delete a wallet.

## 🧾 Transaction Management

- [ ] As a user, I want to add expenses or income manually with details like amount, category, wallet, and date.
- [ ] As a user, I want to edit or delete past transactions.
- [ ] As a user, I want to see a running balance per wallet after each transaction.
- [ ] As a user, I want to filter transactions by date, wallet, or category.

## 📂 Category Management

- [ ] As a user, I want to create my own spending categories (e.g., Food, Bills, Transport).
- [ ] As a user, I want to assign colors to categories for easier recognition.
- [ ] As a user, I want to edit or delete categories.

## 📊 Budget Planning

- [ ] As a user, I want to create budgets based on a specific category.
- [ ] As a user, I want to choose a date range for the budget (start and end date).
- [ ] As a user, I want to view how much I’ve spent against each budget.
- [ ] As a user, I want to see visual progress bars showing remaining budget.
- [ ] As a user, I want to set budgets by percentage (for 50/30/20 tracking style).
- [ ] As a user, I want to choose whether to track all spending or only by category.

## 🔁 Recurring Budgets (optional future feature)

- [ ] As a user, I want to create recurring budgets that reset monthly or weekly.
- [ ] As a user, I want to choose a recurring period: daily, weekly, monthly, or annually.

## 🎯 Savings Goals (optional future feature)

- [ ] As a user, I want to set a savings goal with a target amount and deadline.
- [ ] As a user, I want to allocate funds manually or automatically to a savings goal.

## 📅 Dashboard & Insights

- [ ] As a user, I want to view a summary of my income, expenses, and budgets on the dashboard.
- [ ] As a user, I want to see pie charts or bar graphs of my spending by category.
- [ ] As a user, I want to be alerted when I’m nearing or exceeding a budget.

## 🛠️ Admin / Advanced Features (for future or internal use)

- [ ] As a developer/admin, I want to reset all user data for testing or troubleshooting.
- [ ] As a developer/admin, I want to seed the database with sample data.
